Diana web scanner · autonomous improvement loop

No agent grades its own work

Eight agents turn a missed vulnerability into a merged scanner fix. Every agent that makes something hands it to a different agent to grade, and the last grader is a person.

What each agent is responsible for

Orchestrator opus · local

Runs the seven-step loop in order and refuses to skip a gate. Counts retries, escalates to the user after the limit, and reads the chronicle to detect stalls. It makes no implementation choices and no merge decision.

Makes
Ordering only
Graded by
Nothing to grade

Improvement Agent opus · local

Reads the gap analysis, picks the single highest-impact fix that would help scan any web app, and implements it on a feature branch. One change per iteration, no target-specific code. It only writes code and never runs scans or tests.

Makes
Code diff on a branch
Graded by
Generality, Test Critic, Validation, Review

Generality Agent sonnet · local

Reads every changed line against main. Hard-fails on target names, challenge-aware code, hardcoded responses, or credentials. Warns on stack-specific detection or path assumptions. Its test: would this also help scan a Django, Spring, or Rails app?

Makes
PASS / WARN / FAIL verdict
Graded by
Review Agent checks it was thorough

Test Author sonnet · local

Writes unit tests for the branch from synthetic HTTP responses and neutral URLs. Every happy-path test gets a negative-path twin. No live targets, no captured responses, no sleeps or network.

Makes
Tests under tests/
Graded by
Test Critic

Test Critic sonnet · local

Reads the tests and the code they cover. Asks five questions of each test: correct, complete, independent, generic, isolated. The mutation check is the heart of it: if the feature were deleted, would this test fail? A vacuous test is worse than none.

Makes
PASS / FAIL verdict
Graded by
Review Agent checks it was thorough

Validation Agent haiku · AWS ECS

Builds a Diana image from the branch, runs a fresh full-crawl scan on ECS, fetches the results from S3, and writes the gap analysis. The source of ground truth: solve count, delta against baseline, regressions, and scan duration.

Makes
results.json + gap analysis
Graded by
Review Agent compares to baseline

Tiny-Loop Agent haiku · AWS sandbox

The fast inner loop for a single scanner module. Reuses a cached sitemap, runs only the changed module, and reports which target challenges flipped. Refuses to run if the diff touches the crawler or models. It measures; it never gates a merge.

Makes
Scoreboard delta for one module
Graded by
Generality + full Validation before merge

Review Agent sonnet · local

Gathers every result for the run and scores five criteria: solve rate up, no test regressions, performance within threshold, generality not FAIL, tests sound. All pass means recommend merge. Writes the chronicle entry, the project's memory across iterations.

Makes
Merge recommendation + chronicle
Graded by
Human

Human you

The only reviewer of the only agent whose output needs a person. Reads the Review Agent's recommendation and confirms or declines the merge. No merge happens without this step.

Makes
Merge decision
Graded by
Production
